Pada minggu pertama Oktober 2026, firma keamanan Volexity menyelidiki aktivitas mencurigakan di salah satu klien yang dimonitornya — dan jejaknya berakhir di sebuah appliance Ivanti Connect Secure VPN versi 22.8R2.4 yang saat itu fully patched. Seorang aktor misterius bernama UTA0576 sudah ada di dalam perangkat itu sejak setidaknya 3 Oktober, dua hari sebelum siapa pun menyadari, dilaporkan SecurityAffairs pada 14 Oktober 2026. Senjata masuknya adalah rantai tiga zero-day: authentication bypass plus remote code execution yang dilacak sebagai CVE-2026-104935 (skor CVSS 8.6), lalu sebuah celah privilege escalation yang terpisah. Trik bypass-nya licik — request ke halaman login publik welcome.cgi yang lolos pemeriksaan autentikasi tapi menyisipkan path skrip internal terproteksi lewat HTTP header; sistem mengecek URL untuk memutuskan izin, tapi memakai header untuk memutuskan tujuan, dan ketidakcocokan itu jadi pintunya. Langkah berikutnya: upload skrip Perl yang disamarkan sebagai file ZIP, dieksekusi lewat race condition sebelum server sempat menghapusnya, lalu eskalasi ke root dengan mem-patch in-memory config store milik servis berprivilegi dsinvoked. Semua itu tanpa satu pun login yang valid. Ivanti merilis patch untuk auth bypass dan RCE pada 13 Oktober 2026 — celah privilege escalation-nya masih menunggu update berikutnya — dan CISA langsung memasukkan CVE-2026-104935 ke katalog Known Exploited Vulnerabilities dengan tenggat patch 16 Oktober.

Yang lebih menakutkan dari cara masuknya adalah apa yang dilakukan penyerang setelah berada di dalam. UTA0576 langsung berburu kredensial: tool LDAP kustom yang memakai service account milik appliance VPN itu sendiri untuk memindai Active Directory mencari password LAPS, BitLocker recovery key, dan atribut berisi password plaintext — hasilnya dikompresi, di-encode, dan dieksfiltrasi lewat channel exploit yang sama. Penyerang juga menangkap trafik LDAP mentah untuk memanen kredensial cleartext, membangun implementasi Kerberos sendiri untuk serangan Kerberoasting, dan menjalankan password spraying ke akun-akun domain. Semua dilakukan dengan anti-forensik rapi: setiap perintah dieksekusi dengan mengulang seluruh exploit chain dari awal — tidak ada web shell, tidak ada backdoor persisten — entry log debug dan audit Linux yang relevan dihapus, dan semua perubahan hanya terjadi di memori. Itulah kenapa Ivanti Integrity Checker Tool tidak mendeteksi apa pun: tool itu hanya memeriksa file di disk, sedangkan serangan ini tidak pernah meninggalkan jejak di sana. Volexity juga mencatat dengan medium confidence bahwa UTA0576 kemungkinan memakai LLM untuk mengembangkan exploit dan aktivitas post-exploitation-nya — satu operator yang bekerja seperti satu tim.

Pandangan PMA: ini pengingat keras bahwa VPN adalah aset paling kejam untuk dikelola — dia berdiri paling luar, pegang akses paling dalam, dan kalau jebol dia jadi jembatan ke segalanya. Tiga pelajaran praktis. Pertama, patch bukan lagi soal "versi terbaru aman": appliance ini fully patched saat dibobol, dan integritas checker-nya buta terhadap serangan in-memory — jadi jangan cuma andalkan scan, pasang monitoring perilaku di edge juga. Kedua, alat bantu recovery password seperti LAPS dan BitLocker key recovery berubah jadi liabilitas begitu appliance edge jatuh ke tangan yang salah; rancang segmentasi supaya VPN tidak bisa bicara langsung ke domain controller dengan akun sekuat itu. Ketiga, anggap setiap appliance edge sebagai sudah terekspos: pisahkan, batasi, dan siapkan prosedur forensik memori — karena penyerang hari ini tidak lagi menanam web shell, dia masuk, mengambil, dan menghapus jejak dalam hitungan menit.
