Figma memilih panggung yang tidak biasa untuk mengumumkan langkah AI-nya berikutnya: Config India, edisi pertama konferensi Config di luar Amerika Serikat, digelar 14 Oktober 2026. Bintang utamanya adalah Specs — editor berbasis Markdown tempat tim mendefinisikan design language mereka dalam format yang bisa dibaca manusia sekaligus mesin. Dokumen Specs bisa berdiri sebagai file mandiri di Figma atau menempel di canvas, dan isinya jauh dari sekadar teks: tim bisa me-refer elemen di canvas, menyematkan diagram FigJam, code layers, dan desain lain. Dengan begitu, rules visual, design libraries, code libraries, dan guidelines dikumpulkan jadi satu sumber kebenaran yang bisa dikonsumsi AI agent — dari agent milik Figma sendiri sampai agent pihak ketiga.

Langkah ini menjawab masalah yang sudah lama terasa: agent AI bisa menghasilkan interface dengan sangat cepat, tapi hasilnya sering melenceng dari identitas visual perusahaan. Mengingat AI bersifat non-deterministik, Figma memilih memasang rel, bukan rem — tools yang mengarahkan output ke arah yang lebih predictable. Di acara yang sama, code layers resmi keluar dari private beta ke public beta: desainer kini bisa menanamkan kode langsung di canvas untuk prototype yang lebih interaktif, meminta agent mengubah desain jadi kode, atau mengedit kode untuk iterasi cepat. Figma juga memperluas dukungan Model Context Protocol ke lebih dari 20 tools — termasuk Open Code, Dia, Grok Bot, dan startup AI India Sarvam — serta mengintegrasikan headless CMS Payload (yang diakuisisinya tahun lalu, download-nya naik enam kali lipat) ke produk Figma Make agar website dinamis bisa dibuat dan kontennya dikelola langsung. Pemilihan India pun bukan kosmetik: negara itu kini pasar pengguna terbesar Figma di luar AS, dan 40% dari 100 perusahaan teratas di Bombay Stock Exchange memakai platform ini.

Pandangan PMA: akhirnya design system diperlakukan sebagai kontrak, bukan dekorasi. Specs menarik bukan karena teknologinya — Markdown bukan hal baru — melainkan karena dia mengakui satu realita: agent AI bukan junior designer yang bisa ditegur lewat komentar Figma; dia mesin yang butuh aturan tertulis, terpusat, dan bisa di-parse. Pelajaran praktisnya langsung bisa dipakai tim mana pun, bahkan tanpa Figma Specs: tulis design language kalian dalam satu dokumen plain-text yang hidup, karena dokumen itu sekarang bukan cuma buat onboarding manusia — dia spesifikasi buat mesin. Tim kecil yang hari ini tidak punya design system formal sebenarnya sedang memberi agent AI-nya surat izin untuk menebak. Jangan.
